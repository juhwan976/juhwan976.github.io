## 1. Noomo Showcase (showcase.noomoagency.com)

### 관찰 내용

| 항목 | 관찰 결과 |
| --- | --- |
| 텍스트/비주얼 비율 | 히어로는 타이포 자체가 비주얼(화면 100%). 프로젝트 장면은 비주얼 약 90%, 텍스트 10% 미만 |
| 콘텐츠 최대 너비 | 제한 없음. 풀블리드. 텍스트만 하단 가장자리에 고정 |
| 좌우 여백 | 약 24~40px. 텍스트는 화면 모서리에 붙음 |
| 섹션 간 수직 간격 | 장면 전환형이라 간격 개념이 없음. 스크롤이 카메라를 구동 |
| 제목 크기/줄 수 | 히어로 약 8~10vw 대문자 압축체, 5줄의 타이포 벽 |
| 본문 길이 | 프로젝트당 3줄(약 100자) + 태그 3~5개 |
| 정렬 | 히어로 중앙, 프로젝트 정보는 좌하단/중앙하단 |
| 이미지·3D 배치 | WebGL이 배경이 아닌 주인공. 중앙 크리스탈 오브젝트에 프로젝트 미디어가 담김 |
| 프로젝트 표현 | 프로젝트 1개 = 풀스크린 장면 1개. 장면마다 배경색·조명이 통째로 변화(딥블루 → 흑백) |
| 전환/스크롤 | "Get started" 진입 후 스크롤이 장면 간 카메라 이동을 스크럽. 컷 없음 |
| 내비게이션 | 상단 최소 구성(로고 + 링크 3개 + Send email) |
| 마우스 인터랙션 | 오브젝트가 포인터에 미세 반응, 커서 주변 파티클 |
| 마지막 장면 | 문장 1개 + 이메일만 빛나는 풀스크린 Contact |

### 이 사이트에서 가져올 원칙

- 화면 전체를 사용하는 몰입형 장면 구성. 3D를 장식이 아닌 콘텐츠로.
- 스크롤이 장면 전환(배경·조명 변화)을 구동하는 연속 흐름.
- 화면 중심의 강한 오브젝트 + 가장자리의 최소 텍스트.

## 2. Trionn (trionn.com)

### 관찰 내용

| 항목 | 관찰 결과 |
| --- | --- |
| 텍스트/비주얼 비율 | 히어로 텍스트 약 25%, 3D+여백 75%. Work는 미디어 65% 이상 |
| 콘텐츠 최대 너비 | 사실상 제한 없음(화면 가장자리까지 사용) |
| 좌우 여백 | 약 24~80px. 뷰포트에 비례 |
| 섹션 간 수직 간격 | 최소 20vh 이상. "Key facts"처럼 거대 제목 하나가 빈 화면에 홀로 있는 구간 존재 |
| 제목 크기/줄 수 | 약 96~120px 라이트웨이트, 1~2줄. 로테이션 단어 1개 |
| 본문 길이 | 2~4줄, 최대 너비 약 400~520px |
| 정렬 | 비대칭. 제목 좌상단, 메타 우하단, CTA는 밑줄 모노스페이스 |
| 이미지·3D 배치 | 히어로 중앙 3D 유리 오브젝트, Services는 질감 있는 암석 + 떠다니는 글자 |
| 프로젝트 표현 | 가로 캐러셀. 화면 폭 55%+ 프로젝트 스크린 1개씩. 이름 + 한 줄 + "EXPLORE PROJECT →" |
| 전환/스크롤 | 섹션마다 배경이 다크 ↔ 라이트로 통째로 반전. 스무스 스크롤 |
| 내비게이션 | 로고 + LET'S TALK + MENU 버튼만 |
| 마우스 인터랙션 | "HOLD TO BLAST", 라인 hover 사운드 등 놀이 요소 |
| 모바일 | 동일 콘텐츠를 세로 재배치. 3D 유지·축소, 타이포는 여전히 큼 |

### 이 사이트에서 가져올 원칙

- 매우 큰 제목 + 짧은 문장. 카드 대신 큰 단위의 섹션.
- 넓은 좌우 여백과 네 모서리를 쓰는 비대칭 레이아웃.
- 모노스페이스 밑줄 CTA, 섹션마다 명확하게 달라지는 화면 구성.
- 설명 대신 시각 요소(거대 오브젝트, 배경 반전)로 내용 전달.

## 3. 공통 원칙 → 이 포트폴리오에 적용

1. 한 화면 = 하나의 메시지. 제목 1 + 설명 1 + 수치 ≤3 + CTA ≤1.
2. 콘텐츠를 중앙 컨테이너에 가두지 않는다. 텍스트는 화면 가장자리(모서리)에 배치.
3. 프로젝트 1개 = 풀스크린 장면 1개. 배경 톤이 장면마다 변한다.
4. 본문은 520px, 2~4줄 이내. 기술 스택은 하단 가장자리에 소형 표기.
5. 모션은 장면 전환(배경 톤·마스크 reveal·깊이)에 사용하고 fade-up 반복은 금지.

## 4. 금지 사항 준수

- 두 사이트의 레이아웃 픽셀 복제, 에셋·문구·로고 재사용, 동일 애니메이션 재현은 하지 않는다.
- 디자인 원칙만 추출해 현재 포트폴리오(다크 + 오렌지 악센트, 노드-그래프 모티프, 한국어 카피)에 맞게 재해석한다.
